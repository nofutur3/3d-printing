# Microsoft Surface Arc // Lidl Parkside pegboard holder

A holder for attaching a Microsoft Surface Arc mouse to the Lidl/Parkside pegboard. Remix of [Michal Vyroubal's honeycomb holder](https://www.printables.com/model/599701-microsoft-surface-arc-mouse-honeycomb-holder), adapted to slide into the pegboard's keyhole slots instead.

## Instructions

The mounting tab uses the same keyhole profile as the original Parkside hooks — slide it in from above the same way. Designed and tested for the newer Parkside/Powerfix pegboard with round keyholes; the older square-hole version needs adjustment.

PETG is strongly recommended over PLA — it handles the shear forces from the pegboard slot much better over time.
